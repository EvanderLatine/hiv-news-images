# Карта файлов

Ищите точное имя через `rg --files` или `git ls-files`; изображения сгруппированы одной строкой, потому что все служат тематическими превью. Для назначения файлов сначала смотрите эту карту, затем [AGENTS.md](../AGENTS.md) и [HANDOFF.md](../HANDOFF.md).

## /

- `README.md` — публичное описание банка и адрес публикации изображений.
- `AGENTS.md` — входная точка, правила работы и порядок чтения для AI.
- `HANDOFF.md` — текущее состояние, изменения и очередь.

## docs/

- `docs/FILEMAP.md` — карта всех отслеживаемых файлов репозитория.

## data/image_bank/

- `data/image_bank/*.jpg` — 60 тематических JPEG для превью новостей о ВИЧ.

## scripts/

- `scripts/check_ai_docs.py` — проверка документации, карты файлов и подготовленного коммита.
- `scripts/install-hooks.sh` — установка проверки перед коммитом с сохранением существующего хука.

## tests/

- `tests/test_ai_docs.py` — проверки полного режима, непокрытого файла и установщика хука.
